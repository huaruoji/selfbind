\section{Prompt Construction and Target Definitions}
\label{app:prompts}


This appendix summarizes the prompt construction protocol used for training and evaluation. The full prompt lists are included in the anonymized repository with the experiment code; here we report the counts, categories, and representative examples needed to interpret the benchmark results without duplicating long prompt tables in the PDF. Table~\ref{tab:prompt_inventory} reports the prompt-set sizes; Table~\ref{tab:identity-targets} lists the target entity definitions; Table~\ref{tab:prompt_taxonomy} categorizes the prompt types. Table~\ref{tab:prompt-schema} defines the record schema shared by the v2 benchmark and the stress sets.
